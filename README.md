# C++ Module 09 — 42 Piscine

Container iteration, data parsing, and sorting algorithms. Three exercises combining STL usage with algorithmic thinking.

| Ex | Class | Concept |
|---|---|---|
| ex00 | `BitcoinExchange` | File parsing, map iteration, data lookup |
| ex01 | `RPN` | Stack-based expression evaluation |
| ex02 | `PmergeMe` | Merge-Insert sort, vector vs deque performance |

**Outcomes:**
- `std::map` iteration and range-based lookup
- File I/O with validation and error handling
- Reverse Polish notation evaluation with stack
- Ford-Johnson merge-insert sort algorithm
- Comparing container performance (vector vs deque)

## Build

```bash
cd cpp09/ex00 && make && ./btc <input.txt>
```
