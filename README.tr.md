# C++ Modül 09 — 42 Piscine

Container iterasyonu, veri ayrıştırma ve sıralama algoritmaları. STL kullanımı ile algoritmik düşünceyi birleştiren üç egzersiz.

| Ex | Sınıf | Konsept |
|---|---|---|
| ex00 | `BitcoinExchange` | Dosya ayrıştırma, map iterasyonu, veri arama |
| ex01 | `RPN` | Stack tabanlı ifade değerlendirme |
| ex02 | `PmergeMe` | Merge-Insert sort, vector vs deque performansı |

**Kazanımlar:**
- `std::map` iterasyonu ve range-based arama
- Doğrulama ve hata yönetimi ile dosya I/O
- Stack ile Reverse Polish notation değerlendirme
- Ford-Johnson merge-insert sort algoritması
- Container performans karşılaştırması (vector vs deque)

## Derleme

```bash
cd cpp9/ex00 && make && ./btc <input.txt>
```
